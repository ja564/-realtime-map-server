# 实时互助地图 / Realtime Mutual-Help Map

我开发了一个 **【实时互助地图】** 小工具，专门分享最新的路况动态，帮大家避开不必要的麻烦。

在线体验地址：  
https://map.orange3dfashion.com
OR
https://map.xianquan.net

## 开发背景

近年来，各地对电动车、摩托车的管理持续加强，路面巡查和临时检查更加频繁。  
很多通勤者骑到路口才发现有临检或临时封路，不仅耽误时间，也增加了不必要的风险。
<img width="588" height="533" alt="image" src="https://github.com/user-attachments/assets/54ce9f9d-93da-471a-a818-26cd8e7906e7" />

传统信息获取方式（微信群聊天、零散消息转发）存在几个问题：

- 信息分散，无法在地图上直观查看；
- 时效性差，过时信息难以及时清理；
- 无统一入口，新人很难快速了解路况。


**实时互助地图** 希望用一个极简的小工具，让每一位路过的人都可以“顺手上报”，  
把即时路况沉淀到一张共享地图上，帮助更多人提前规避风险。

## 功能介绍

### 使用指南

- **实时预览**  
  打开网页即可看到当前视野内所有还在有效期内的上报事件点。

- **一键上报**  
  在地图上点击事件发生点，填写简单描述，即可标注：  
  - 交警巡逻/临检  
  - 路段封锁、施工  
  - 临时检查、其他异常情况

- **时效机制**  
  为确保信息新鲜可靠，每条上报具有**时效性**：  
  - 默认有效期：**180 分钟**；  
  - 过期点会自动从地图上清除；  
  - 若情况仍在持续，可在点消失后重新上报一次。

### 产品优势

- **零延迟**：前端与云端服务实时交互，地图视图即时更新。  
- **轻量化**：无需下载 App，手机/电脑浏览器直接访问即可使用。  
- **纯净专注**：不做复杂社交和推送，只专注一件事——**让你随时掌握路上的动态**。  
- **匿名友好**：只记录地点与事件内容，不采集多余个人信息。

## 技术栈与实现

- **前端**
  - `Vue 2` + 单文件组件架构
  - `MapLibre GL JS`：地图渲染与交互
  - 原生 `Fetch API` 进行数据请求
  - `Service Worker` + `Web App Manifest` 支持 PWA / 添加到桌面

- **后端与数据**
  - Node.js + Express 简易 API
  - MongoDB / 文档数据库存储事件点
  - 定时任务 / 过期策略：仅返回未过期事件，并定期清理旧数据

- **部署**
  - 前端静态站点部署（cloudflare）
  - 后端部署在云端 Node.js 服务（如 Render 等）

## 解决的问题

- **信息“看不见”**：  
  将群聊中零散的“这里有检查”“那边封路了”转成可视化的地理事件点，一眼看懂哪里需要绕行。

- **信息“过期但还在”**：  
  通过 180 分钟有效期与服务端清理策略，自动淘汰过期上报，降低“假警报”和历史噪音。

- **参与门槛高**：  
  无需注册、无需安装，打开网页即可浏览路况，一点地图即可完成上报，降低参与门槛。

- **跨终端体验**：  
  通过 PWA 支持，用户可以将网页安装到手机桌面，当作轻量 App 使用。
